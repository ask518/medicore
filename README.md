# MEDICORE – Enterprise Multi-Tenant Healthcare Management SaaS
## المنصة السحابية الموحدة لإدارة العيادات والمجمعات والمراكز الطبية التخصصية

---

### نظرة عامة | Overview
**MEDICORE** هي منصة برمجية سحابية تجارية متكاملة متعددة المستأجرين (Multi-Tenant SaaS) ومصممة بالكامل وفقاً لأحدث المعايير الهندسية والطبية لإدارة العيادات الفردية، العيادات التخصصية المشتركة، المجمعات والمراكز الطبية الشاملة، مع دعم خيار النشر المخصص للمؤسسات والمستشفيات الكبرى (**Dedicated Enterprise Edition**).

تم بناء النظام بالكامل وفق نموذج **No-VPS Architecture** (بدون الحاجة لشراء أو إدارة خوادم تقليدية)، بالاعتماد على الخدمات السحابية المدارة منخفضة التكلفة والصديقة للباقات المجانية (Managed Cloud BaaS):
- **الواجهة الأمامية (Frontend):** React 18 + TypeScript + Vite + Tailwind CSS + Lucide Icons + PWA.
- **الاستضافة السحابية للواجهة:** Vercel / Cloudflare Pages / Firebase Hosting (Static Build).
- **قاعدة البيانات والتحكم بالهوية (BaaS):** Supabase Managed Cloud (PostgreSQL 15+ مع Row Level Security و Auth و Storage و Triggers).
- **محرك المحاكاة والاختبار السريع (Dual-Mode):** محرك بيانات محلي فائق السرعة مدمج يتيح العمل والتجربة فوراً بدون إنترنت أو إعدادات مسبقة، مع التوصيل الفوري بسحابة Supabase بمجرد وضع مفاتيح الربط في ملف `.env`.

## نماذج النشر والتشغيل (Deployment Profiles)

يدعم النظام نمطين تشغيليين من نفس الكود المصدري عبر متغيرات البيئة (`VITE_DEPLOYMENT_PROFILE`):

### 1. Model A – السحابة العامة متعددة المستأجرين (Multi-Tenant SaaS)
- تشترك كافة العيادات والمراكز في نفس قاعدة البيانات.
- عزل أمني صارم للبيانات على مستوى قاعدة البيانات عبر سياسات **Row Level Security (RLS)** بواسطة `organization_id`.
- إدارة الاشتراكات الشهرية والسنوية والحدود المسموح بها لكل باقة من لوحة مالك المنصة.

### 2. Model B – الإصدار المخصص للمؤسسات الكبرى (Dedicated Enterprise)
- نشر مخصص لمجمع طبي ضخم أو مستشفى في بيئة وقاعدة بيانات مستقلة تماماً.
- نطاق مخصص (Custom Domain مثل `clinic.alnoor-medical.com`).
- هوية بصرية مخصصة وألوان خاصة.

## المكونات والوحدات الرئيسية المكتملة

### 1. لوحة تحكم مالك المنصة (Super Admin Dashboard)
- مراقبة كافة المنشآت الطبية المسجلة مع إحصائيات الفروع والأطباء وحجم التخزين.
- محرك الدخل السحابي: حساب الدخل الشهري المتكرر (**MRR**) والدخل السنوي المتوقع (**ARR**).
- إدارة باقات الاشتراك (Starter, Professional, Medical Center, Enterprise) وتعديل الأسعار والحدود المسموح بها ديناميكياً بدون كود ثابت.
- اعتماد أو إيقاف أو تنشيط المنشآت الطبية.
- سجل التدقيق الأمني المباشر (Security Audit Trail) لكافة العمليات الحساسة.

### 2. إدارة الفروع والصلاحيات (Branches & RBAC)
- دعم الفروع المتعددة لكل مجمع (مثل فرع مدينة نصر، فرع التجمع الخامس).
- نظام تحكم وصول مبني على الأدوار (**Role-Based Access Control**):
  - مالك المنصة (Super Admin)
  - مالك المنشأة (Organization Owner)
  - المدير العام ومدير الفرع (Branch Manager)
  - استشاري / طبيب معالج (Doctor)
  - طبيب مقيم / مساعد (Assistant Doctor)
  - تمريض (Nurse)
  - موظف استقبال (Receptionist)
  - مدير مالي / محاسب (Accountant)
  - أخصائي تحاليل وأشعة (Lab & Radiology Technicians)
  - صيدلي ومسؤول تأمين طبي (Pharmacist & Insurance Officer)
  - مريض (Patient)

### 3. السجل الطبي الإلكتروني الشامل (EMR)
- رقم طبي موحد لكل مريض (**MRN**) وبيانات ديموغرافية كاملة.
- تسجيل الحساسيات الدوائية والغذائية مع مؤشرات التحذير الإكلينيكي (Penicillin Allergies, etc.).
- الأمراض المزمنة والعمليات الجراحية السابقة.
- خط زمني سريري تراكمي (Chronological Medical Timeline) غير قابل للحذف أو التعديل الصامت.

### 4. إدارة المواعيد وجدول العيادات (Appointment Engine)
- جدول زمني دقيق لكل طبيب وفرع وغرفة كشف.
- **قاعدة منع الحجز المزدوج (Double-Booking Prevention Guard):** منع حجز موعدين لنفس الطبيب في نفس الدقيقة برمجياً وقاعدياً.
- طابور الاستقبال المباشر وصالة الانتظار (Live Waiting Room Queue) مع تتبع الحالات (مؤكد، وصل، بالانتظار، داخل العيادة للكشف، مكتمل).

### 5. عيادة الطبيب والفحص السريري (Doctor Consultation Desk)
- تسجيل العلامات الحيوية (ضغط الدم، النبض، الحرارة، الوزن، الطول) مع حساب تلقائي لمؤشر كتلة الجسم (**BMI**).
- دليل تشخيصي مدعوم بترميز منظمة الصحة العالمية (**ICD-10**).
- الخطة العلاجية والروشتة الإلكترونية المعتمدة (**e-Prescription**) من دليل دوائي معتمد.
- توقيع واعتماد الكشف رقمياً وقفله لمنع أي تعديل صامت غير موثق.

### 6. المحركات التشخيصية التفاعلية للتخصصات (Specialty Canvases)
- **جراحة العظام (Orthopedics):** هيكل عظمي بشري تفاعلي ثلاثي الأبعاد (Anterior & Posterior)، وتحديد الكسور والخلع وتمزق الأربطة مع مقياس الألم (0-10).
- **طب وجراحة الأسنان (Dentistry):** مخطط أسنان تفاعلي بنظام الترقيم العالمي (**FDI 2-Digit**)، يشمل أسنان البالغين الدائمة (32 سن) وأسنان الأطفال اللبنية (20 سن)، مع توثيق أسطح السن (Occlusal, Mesial, Distal, Buccal, Lingual) والحالات (تسوس، حشو كمبوزيت/أملجم، تاج، علاج جذور، زراعة، خلع).
- **الأمراض الجلدية (Dermatology):** خريطة تفاعلية لسطح الجسم لتسجيل الآفات الجلدية وتحديد النوع الإكلينيكي (Macule, Papule, Plaque, Nodule, Ulcer) مع الحجم بالملليمتر ولون الآفة والأعراض (حكة، نزيف، ألم).
- **طب العيون (Ophthalmology):** فحص مقاييس وحدة الإبصار للعينين (OD / OS)، قياس ضغط العين (Tonometry IOP mmHg)، فحص القرنية وعدسة العين وقاع العين والشبكية.

### 7. الإدارة المالية والمحاسبية (Financial & Invoicing)
- إصدار الفواتير التفصيلية للخدمات والكشوفات.
- تحصيل الدفعات بإيصالات مرقمة رسمية ودعم طرق دفع متعددة (نقداً، فيزا، تحويل بنكي، فودافون كاش، فوري).
- إدارة الخزائن اليومية وأرصدتها اللحظية والإغلاق اليومي.
- حساب نسب وأتعاب وعمولات الأطباء تلقائياً عند السداد.
- قيود مالية غير قابلة للحذف، واستخدام قيود الإلغاء والتسوية الموثقة.

### 8. الفحوصات المعملية والأشعة (Laboratory & Radiology)
- دليل التحاليل الطبية مع الأسعار والمدى المرجعي الطبيعي (Reference Ranges).
- طلبات الأشعة (X-Ray, CT, MRI, Ultrasound, Mammography) مع جاهزية ربط عارض الـ DICOM.

### 9. بوابة المريض الإلكترونية (Patient Health Portal)
- واجهة مستقلة للمريض للاطلاع على مواعيده وحجز كشوفات جديدة أونلاين.
- استعراض الروشتات الطبية المعتمدة وطباعتها.
- استعراض نتائج التحاليل والفحوصات المعتمدة.

### 10. معالج استيراد البيانات التاريخية (Data Migration Wizard)
- استيراد سجلات المرضى السابقة من ملفات Excel و CSV.
- مطابقة الأعمدة والتحقق من صحة الحقول وفحص التكرار تلقائياً لحماية سلامة السجلات.

## تعليمات التشغيل والبناء السريع

### 1. تثبيت الحزم (Dependencies):
```bash
npm install
```

### 2. تشغيل السيرفر المحلي للتطوير (Development):
```bash
npm run dev
```
سيفتح التطبيق فوراً على المنفذ `http://localhost:3000` بكامل وظائفه.

### 3. بناء نسخة الإنتاج (Production Build):
```bash
npm run build
```
يقوم بتشغيل فحص الأنواع الصارم عبر `tsc` وتوليد الحزم المحسنة والمضغوطة داخل مجلد `dist/`.

### 4. تشغيل سويت الاختبارات الآلية (Verification Suite):
```bash
node scripts/verify-medicore.mjs
```
يقوم بالتحقق التلقائي مع طباعة الأدلة السريرية من:
- وجود منشأتين طبيتين منفصلتين.
- العزل التام لبيانات المرضى وعدم قدرة أي منشأة على استرجاع مرضى المنشأة الأخرى.
- تفعيل واعتراض قاعدة منع الحجز المزدوج.
- سلامة العمليات المالية وتحديث رصيد الخزينة عند التحصيل.
- توثيق التوقيع الرقمي بسجل التدقيق الأمني.

## إعدادات الربط السحابي (Supabase Setup - No VPS)

1. أنشئ مشروعاً مجانياً على [Supabase](https://supabase.com).
2. من لوحة تحكم المشروع، افتح **SQL Editor** ونفّذ ملفات الـ SQL الموجودة في مجلد `supabase/migrations/` بالترتيب:
   - `20261122000001_initial_schema.sql`
   - `20261122000002_rls_policies.sql`
   - `20261122000003_functions_triggers.sql`
   - `20261122000004_seed_data.sql`
3. انسخ الـ `Project URL` و الـ `anon public key` من إعدادات المشروع إلى ملف `.env`:
```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGci...
```
4. ارفع مجلد `dist/` إلى **Vercel** أو **Cloudflare Pages** بضغطة زر وبدون أي تكاليف سيرفرات!
